# mini-lualatex
A minimal LuaLaTeX tarball, that facilitates LaTeX compilation of accessible transcriptions for physics videos inside of a cloud-based Python notebook, such as Colab.

This project contains:

WorkingExample.ipynb: Example Notebook that can be used (with small modifications) to compile .tex files inside of a users Google Drive.

LuaLaTeXCreateLocalInstallandTest.ipynb: Developer notebook for updating the tarball here. The tar.gz which was created in Colab is too big to stick in a github repo, but each version will be attached as a release until we can do something a little better.
